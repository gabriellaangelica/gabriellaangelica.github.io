# Gabriella Angelica Jemima Hasian — Data Science Blog

This repository contains my personal Quarto website and blog for DSCI 521. It includes two computational posts, one written in Python and one in R, using the Palmer Penguins dataset.

## Requirements

Install the following software before building the site:

- Quarto 1.10.18 or later
- Python 3.14
- uv
- R 4.6.1 or later
- Git

The Python environment is managed with `uv`. The R environment is managed with `renv`.

## Build the site from a fresh clone

Clone the repository and move into the repository directory:

```bash
git clone https://github.com/gabriellaangelica/gabriellaangelica.github.io.git
cd gabriellaangelica.github.io
